## Description

FocusSound is a sleek, minimalist ambient sound mixer designed to help users block out distractions, boost productivity, and craft their perfect acoustic environment. Built with vanilla frontend technologies, it allows users to dynamically blend high-quality, public-domain audio loops such as rain, ocean waves, café chatter, and brown noise.

## Features

- **Dynamic Audio Blending:** Independently toggle multiple ambient tracks and fine-tune individual volume levels simultaneously.
- **Performance Optimized Lazy-Loading:** Audio assets do not load into memory until a track is explicitly activated, ensuring blistering initial page speeds.
- **Smart Active States:** Intelligent UI safeguards automatically nudge muted sliders to 50% volume if a user activates a silent track, complete with an explicit card-shaking micro-interaction.
- **Master Global Controls:** Instant "Pause All" and "Reset" features to completely clear or normalize your workspace in one click.
- **Immersive Responsive UI:** Animated atmospheric background orbs, responsive card transitions, glassmorphism panel layouts, and dynamic canvas element gradients customized per audio track.
